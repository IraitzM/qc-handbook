# Paquetes de software

* [QuTiP](https://qutip.org/): Toolbox cuántico para simular la dinámica de sistemas cuánticos.
* [Qiskit](https://www.ibm.com/quantum/qiskit): Kit de desarrollo de IBM, el estándar indiscutible para el desarrollo de software cuántico basado en puertas.
* [Ocean SDK](https://www.dwavequantum.com/solutions-and-products/ocean/): SDK propietario de D-Wave. Muy útil para plantear problemas y crear las primeras instancias de nuestros problemas particulares antes de pasar a annealers, dispositivos basados en puertas o el solver final.
* **Bloqade** de QuEra para simular plataformas de átomos neutros tanto en [Julia](https://queracomputing.github.io/Bloqade.jl/dev/) como en [Python](https://queracomputing.github.io/bloqade-analog/latest/)
* [Amazon Braket](https://aws.amazon.com/es/braket/) para simulación y envío de trabajos al servicio Amazon Braket.
* [Pennylane SDK](https://pennylane.ai/) para Quantum Machine Learning, entre otros temas.
* [QUIMB](https://quimb.readthedocs.io/en/latest/index.html) para aquellos que quieran profundizar en _cosas_ de redes tensoriales.
* [sQUlearn](https://squlearn.github.io/) enfocado en QML con gran documentación
* [TensorFlow Quantum](https://www.tensorflow.org/quantum) mirando la interoperabilidad entre el mundo clásico y cuántico.
* [TensorKrowch](https://joserapa98.github.io/tensorkrowch/_build/html/index.html)
* [Quantum Tea](https://www.quantumtea.it/) para aplicaciones de Tensor Network
* [QIBO](https://qibo.science/) para simulación y trabajar como middleware

## Para formulación de problemas

* [QUBOVERT](https://qubovert.readthedocs.io/en/latest/index.html)

## Para compilación y transpilación

* [pytket](https://tket.quantinuum.com/): compilador TKET de Quantinuum, retargetable y disponible como plugin para la mayoría de los SDKs.
* [PyZX](https://github.com/zxcalc/pyzx) para simplificación de circuitos vía reescritura ZX-calculus.
* [BQSKit](https://bqskit.lbl.gov/) para resíntesis numérica de bloques de circuito.
* [Superstaq](https://superstaq.readthedocs.io/en/latest/) para compilación consciente del dispositivo entre proveedores.
* [Stim](https://github.com/quantumlib/Stim) para simulación muy rápida de circuitos stabilizer, la herramienta referencia para trabajo de corrección de errores.

Más sobre cómo encajan todo en [la pila de computación cuántica](../computers/stack.md).
