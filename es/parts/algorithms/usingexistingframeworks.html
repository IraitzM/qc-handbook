1  D-Wave y su ecosistema

En este notebook profundizaremos en las herramientas que ofrecen D-Wave y su ecosistema para abordar problemas combinatorios.

Para estos ejercicios usaremos las siguientes librerías: PyQubo, además de dimod y dwave-ocean-sdk de la suite Ocean de DWave.

Normalmente, al instalar el SDK se instalan también las otras dos dependencias, pero por si acaso comprueba que están todas.

import dimod

h = {1: 1, 2: 1}
J = {(1, 2): 1}

dimod.ising_to_qubo(h, J, 0.5)
({(1, 1): 0.0, (2, 2): 0.0, (1, 2): 4.0}, -0.5)

PyQubo permite plantear estas formulaciones de forma sencilla, expresarlas con claridad y obtener después la matriz QUBO o los coeficientes de Ising.

1.1 Optimización de carteras

La optimización de carteras es un ejercicio sencillo que encaja muy bien con el tipo de formulación que queremos construir. Parte de la definición del trabajo pionero de Markowitz.

\[ \max \sum_i r_ix_i - \sum_i \sum_j c_{ij}x_ix_j \\ \text{ s. t. } \sum_i b_ix_i \le B \]

donde \(r_i\) representa la rentabilidad de un activo y \(c_{ij}\) es el riesgo de que ambos activos dependan de los mismos factores. Conviene diversificar cuando se trata de carteras de inversión. \(b_i\) es el coste de invertir en un activo y \(B\) es todo el presupuesto del que disponemos.

QUBO

\[\begin{equation} \begin{split} \min_{x_{i}\in{\{0,1\}}} \;\; & \theta_{1}\sum_{i=1}^{n}-x_{i}r_i \\ \;\; +\;&\theta_{2}\sum_{i,j=1}^{n}x_{i}x_{j}c_{ij} \\ +\;&\theta_{3}\left(\sum_{i=1}^{n}x_{i}b_{i}-B\right)^{2} \end{split} \end{equation}\]

Los parámetros \(0\leq\theta_{1},\theta_{2},\theta_{3}<\infty\) representan la importancia relativa de cada término para quien toma la decisión, que puede ajustarlos libremente para reflejar mejor sus preferencias.

Elijamos un conjunto de activos y sus características (rentabilidad y covarianza).

import numpy as np

r_i = np.array([77.60417796, 29.71772711, 19.06733564, 32.14568747, 95.12069674, 32.7466954 , 56.48788447])

b_i = np.array([75, 23, 20, 33, 95, 29 , 25])

B = sum(b_i)*0.66

                 [ 19.59907177, -14.78713228,  -5.10928035, -31.74061021, 16.74718009, -26.58473057,  40.90234169]])
from pyqubo import Array, Placeholder, Constraint

num_assets = len(r_i)
x = Array.create('x', shape=num_assets, vartype='BINARY')
# Profit generated by each asset individually
H_linear_profit = 0.0
for i in range(num_assets):
    H_linear_profit += Constraint(
        r_i[i] * x[i], label='profit({})'.format(i)
    )
# Risk obtained from the covariance matrix
H_quadratic = 0.0
for i in range(num_assets):
    for j in range(i + 1, num_assets):
        H_quadratic += Constraint(
            c_ij[i][j] * x[i] * x[j], label='risk({}, {})'.format(i, j)
        )
# Constraint (budget)
H_linear_budget = 0.0
for i in range(num_assets):
    H_linear_budget += Constraint(b_i[i]*x[i], label='slot({})'.format(i))
# Build model.
theta1 = Placeholder('theta1')
theta2 = Placeholder('theta2')
theta3 = Placeholder('theta3')
H = - theta1*H_linear_profit + theta2 * H_quadratic + theta3 * (H_linear_budget - B)**2
model = H.compile()

Los datos ya están incluidos en el modelo, pero podemos elegir los parámetros de regularización y jugar con ellos para encontrar un buen equilibrio si no tenemos ninguna intuición previa.

# Set the Lagrange multipliers
theta1=0.5 
theta2=0.3
theta3=0.2
feed_dict = {'theta1': theta1, 'theta2' : theta2, 'theta3' : theta3}

# Transform to QUBO.
qubo, offset = model.to_qubo(feed_dict=feed_dict)
import dimod

sampler = dimod.ExactSolver()

response = sampler.sample_qubo(qubo)

Ahora podemos llevar nuestro ejemplo a los samplers de D-Wave y ver qué obtenemos. Asegúrate de copiar tu token en el código de abajo.

import minorminer
from dwave.system.samplers import DWaveSampler
from dwave.system.composites import FixedEmbeddingComposite

# Instantiate Sampler
dwave_sampler = DWaveSampler(token="<your-token>")

# Construct a problem
bqm = dimod.BinaryQuadraticModel(qubo, dimod.BINARY)

# Get the edge list
target_edgelist = dwave_sampler.edgelist

# And source edge list on the BQM quadratic model
source_edgelist = list(bqm.quadratic)

# Find the embedding
embedding = minorminer.find_embedding(source_edgelist, target_edgelist)
sampler = FixedEmbeddingComposite(dwave_sampler, embedding)
# DWave sampler parameters
amode = 'histogram'
allowed_ta = dwave_sampler.properties['annealing_time_range'] #microsecond
num_reads=100
ta = 10 # microseconds
response = sampler.sample_qubo(qubo, num_reads=num_reads, annealing_time=ta, answer_mode=amode)
print(response.slice(10))

1.2 Max Cut

import networkx as nx

# Create empty graph
G = nx.Graph()

# Add edges to the graph (also adds nodes)
G.add_edges_from([(1,2),(1,3),(2,4),(3,4),(3,5),(4,5)])

nx.draw(G)
from collections import defaultdict

# Initialize our Q matrix
Q = defaultdict(int)

# Update Q matrix for every edge in the graph
for i, j in G.edges:
    Q[(i,i)]+= -1
    Q[(j,j)]+= -1
    Q[(i,j)]+= 2
from dwave.system.samplers import DWaveSampler
from dwave.system.composites import EmbeddingComposite

# Set up QPU parameters
chainstrength = 8
numruns = 10

# Run the QUBO on the solver from your config file
sampler = EmbeddingComposite(DWaveSampler(token="<your-token>"))
response = sampler.sample_qubo(Q,
                               chain_strength=chainstrength,
                               num_reads=numruns,
                               label='Example - Maximum Cut')
print('-' * 60)
print('{:>15s}{:>15s}{:^15s}{:^15s}'.format('Set 0','Set 1','Energy','Cut Size'))
print('-' * 60)
for sample, E in response.data(fields=['sample','energy']):
    S0 = [k for k,v in sample.items() if v == 0]
    S1 = [k for k,v in sample.items() if v == 1]
    print('{:>15s}{:>15s}{:^15s}{:^15s}'.format(str(S0),str(S1),str(E),str(int(-1*E))))

Un detalle importante es que, aunque partíamos de \(2^N\) soluciones posibles, al final solo obtenemos 2 con el mismo valor de energía. Así, nuestro estado cuántico es la superposición de todas esas soluciones óptimas y, por tanto, el estado fundamental.

from matplotlib import pyplot as plt

lut = response.first.sample

# Interpret best result in terms of nodes and edges
S0 = [node for node in G.nodes if not lut[node]]
S1 = [node for node in G.nodes if lut[node]]

uncut_edges = [(u, v) for u, v in G.edges if lut[u]==lut[v]]
